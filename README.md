🌐 Social Network Simulator using C

📌 About the Project

The Social Network Simulator is a menu-driven C project that represents users and their friendships using a graph data structure.

The project demonstrates fundamental Data Structures and Algorithms concepts such as Graphs, Linked Lists, BFS, DFS, and Searching.

🚀 Features

* Add User
* Add Friendship
* Display Users
* Display Friends
* Search User
* Find Mutual Friends
* Explore Network using DFS
* Explore Network using BFS

🧠 DSA Concepts Used

* Graph
* Adjacency List
* Linked List
* Breadth First Search (BFS)
* Depth First Search (DFS)
* Searching
* Structures

🛠️ Technology

* C Programming
* Data Structures and Algorithms

▶️ How to Run

Compile the program using a C compiler:

gcc social_network.c -o social_network

Run the program:

./social_network
